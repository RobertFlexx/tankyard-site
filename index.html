    Install

    Latest release
      Step 1 of 4
      Windows

      64-bit Windows. The C runtime is included. PCs with ARM processors run the x64 build. Remove it from Installed apps; settings and progress are kept.

      macOS

      macOS 11 or newer. One universal build runs natively on Apple silicon and Intel Macs. The dedicated server, bundled mods and guides are inside Tank Yard.app.

      Linux

      x86-64 with glibc 2.31 or newer, or ARM64 with glibc 2.35 or newer. Uses your system's X11 and OpenGL libraries.

      FreeBSD

      FreeBSD 15 or newer on amd64, with alsa-plugins and an X11 desktop. Works with NVIDIA's driver and Mesa. FreeBSD guide

      FreeBSD® and the FreeBSD® logo are registered trademarks of The FreeBSD Foundation. Tank Yard is not affiliated with or endorsed by the Foundation.

      Every download is listed with its SHA-256 checksum under What's new, and the installers check it for you. Building from source needs Rust 1.88 or newer:
      git clone https://github.com/RobertFlexx/tankyard && cd tankyard cargo build --locked --release --workspace ./target/release/tankyard

        Motions, lights and particles

        Lights and particles

        Torches, lanterns, neons and effects

        Torches waver like flames, lanterns spread a wide, soft light and neons glow steady. Lights add to whatever lies beneath them, so they shine brightest on a dark floor. Each particle preset fills in every setting at once.

        Also new in the workshop
        • Shift

          Straight motions. Drag the diamond at a selected motion's arrow to set where it goes. It snaps to the grid, and Shift keeps it straight.

        • CtrlShiftA

          Select alike. Selects everything like the selection, such as every light or every speed pad, so one change reaches them all.

        • P

          Preview in place. Runs the map's logic on the canvas. Moved objects show a dashed outline where the map puts them, and Fire plays any one trigger.

        • Remembered

          Back where you were. The workshop remembers the palette tab and item, the inspector tab, the preview's speed and where you were looking.

        Bosses

        14 bosses

        One random boss can arrive in Free For All, Two Teams, Four Teams, Maze and Random Events, after a one-minute grace period. An alarm sounds, a banner names it, and when it falls the banner names the tank that did the most damage. Boss Rush sends six waves.

        Play together

        Main server, parties and community servers

        Main server

        Play or Enter on the title screen joins tankyard.kokonico.me. Busy times split into arenas of twenty players; the server name shows which one you joined. Click the server card to pick a lobby.

        Parties

        An invite-only match hosted on the leader's computer, with proximity voice and party chat. Internet invites detect your public address and try router forwarding for you.

        Community server

        Host server → Community server starts a server as its own process, so it keeps running while you play anywhere. Your enabled mods run on it; players download nothing. The same server runs without the game on a spare PC, a VPS or a Raspberry Pi.

        Your own hostname

        A built-in WebSocket listener lets friends join play.example.com over HTTPS behind Caddy or nginx. The domain guide covers DNS and certificates.

        Mods

        Scripted in Luau

        A pack can add game modes, scoring rules, tanks, maps, bosses on a timer, HUD widgets, skins and a restyled menu. It runs on the server in a sandbox, so players who join need nothing installed.

        • Scripts react to kills, deaths, rounds and map events, award score and draw HUD widgets.
        • Editor plugins add tools and map checks to the Arena Workshop. Every edit a tool makes is one undo step.
        • The Mods page imports a .zip or folder, shows every file inside, and runs a safety review that flags code trying to reach your computer.
        • Packs from the old LuaJIT sandbox still run unchanged.
